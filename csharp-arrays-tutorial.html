📦 What is an Array?
Level 1 of 8 — The foundation

An array is a fixed-size collection of elements of the same type, stored in contiguous memory. Think of it as a row of numbered boxes.

42[0]
17[1]
99[2]
5[3]
73[4]
💡
Arrays in C# start at index 0. A 5-element array has indices 0, 1, 2, 3, 4.

Why use arrays?

  • Store many values under one variable name
  • Access any element in O(1) constant time
  • Ideal when size is known at creation
  • More memory-efficient than object lists

Tap an index to highlight it

Index [0] holds value 42

Arrays vs Variables

// Without array — messy!
int score1 = 42;
int score2 = 17;
int score3 = 99;

// With array — clean!
int[] scores = { 42, 17, 99 };

✍️ Declaring & Initialising
Level 2 of 8

The general syntax for declaring an array in C#:

type[] name = new type[size];

Examples:

// integer array of 5 elements
int[] numbers = new int[5];

// string array of 3 elements
string[] names = new string[3];

// double array
double[] prices = new double[10];
⚠️
The size must be a non-negative integer and cannot be changed after creation.

Way 1 — Declare then assign

int[] nums = new int[3];
nums[0] = 10;
nums[1] = 20;
nums[2] = 30;

Way 2 — Inline initializer

int[] nums = new int[] { 10, 20, 30 };

Way 3 — Shorthand (most common)

int[] nums = { 10, 20, 30 };
💡
Way 3 is the most concise and the one you'll use most often in practice.

When you create an array with new without values, elements get default values:

0int
0.0double
falsebool
nullstring
'\0'char
int[] arr = new int[3];
// arr = [0, 0, 0]  ← default!

bool[] flags = new bool[3];
// flags = [false, false, false]

string[] words = new string[3];
// words = [null, null, null]

🎯 Accessing Elements
Level 3 of 8

Use the index operator [] to read or write individual elements.

string[] fruits = { "Apple", "Banana", "Cherry", "Date" };

// Read
Console.WriteLine(fruits[0]); // "Apple"
Console.WriteLine(fruits[2]); // "Cherry"

// Write
fruits[1] = "Blueberry";
// fruits = ["Apple","Blueberry","Cherry","Date"]

The .Length Property

int[] arr = { 5, 10, 15, 20 };
Console.WriteLine(arr.Length); // 4

// Last element = arr[arr.Length - 1]
Console.WriteLine(arr[arr.Length - 1]); // 20

Index from End (C# 8+)

// ^ means "from the end"
Console.WriteLine(arr[^1]); // 20 (last)
Console.WriteLine(arr[^2]); // 15 (second to last)

Ranges (C# 8+)

int[] arr = { 1, 2, 3, 4, 5 };
int[] slice = arr[1..4]; // [2, 3, 4]
int[] last3 = arr[^3..]; // [3, 4, 5]
🚨
IndexOutOfRangeException — accessing an index that doesn't exist throws this runtime error. Always stay within 0 to Length - 1.

🔁 Looping Over Arrays
Level 4 of 8

The for loop gives you full control — you know the index at every step.

int[] scores = { 85, 92, 78, 96, 88 };

for (int i = 0; i < scores.Length; i++)
{
    Console.WriteLine($"scores[{i}] = {scores[i]}");
}
// scores[0] = 85
// scores[1] = 92  ...etc
💡
Use for when you need the index, or want to go backwards, or need to modify elements.

foreach is cleaner when you only need the values.

string[] colors = { "Red", "Green", "Blue" };

foreach (string color in colors)
{
    Console.WriteLine(color);
}
// Red
// Green
// Blue
⚠️
foreach variables are read-only — you cannot assign to color inside the loop to change the array.

while loop — useful when the stopping condition is complex.

int[] arr = { 3, 7, 2, 9, 1 };
int i = 0;

while (i < arr.Length)
{
    Console.Write(arr[i] + " ");
    i++;
}
// 3 7 2 9 1

Common patterns you must know:

// Sum all elements
int sum = 0;
foreach (int n in arr) sum += n;

// Find maximum
int max = arr[0];
for (int i = 1; i < arr.Length; i++)
    if (arr[i] > max) max = arr[i];

// Reverse loop
for (int i = arr.Length - 1; i >= 0; i--)
    Console.Write(arr[i] + " ");

// Find an element
bool found = false;
foreach (int n in arr)
    if (n == 7) { found = true; break; }

🛠️ Array Methods & System.Array
Level 5 of 8

The static Array class provides powerful built-in methods.

int[] arr = { 5, 2, 8, 1, 9 };

// Sort ascending (modifies in-place)
Array.Sort(arr);
// arr = [1, 2, 5, 8, 9]

// Reverse
Array.Reverse(arr);
// arr = [9, 8, 5, 2, 1]

// Sort strings alphabetically
string[] names = { "Zara", "Alice", "Bob" };
Array.Sort(names);
// ["Alice", "Bob", "Zara"]
int[] arr = { 1, 2, 5, 8, 9 }; // must be sorted!

// Binary Search (O log n) — array must be sorted
int idx = Array.BinarySearch(arr, 5);
// idx = 2

// IndexOf — finds first occurrence
int pos = Array.IndexOf(arr, 8);
// pos = 3

// Returns -1 if not found
int missing = Array.IndexOf(arr, 99);
// missing = -1

// Exists — check with a condition
bool hasLarge = Array.Exists(arr, x => x > 7);
// true (8 and 9 qualify)
int[] src = { 1, 2, 3, 4, 5 };
int[] dst = new int[5];

// Copy entire array
Array.Copy(src, dst, src.Length);

// Clone (creates new array)
int[] clone = (int[])src.Clone();

// Fill all elements with same value
Array.Fill(dst, 42);
// dst = [42, 42, 42, 42, 42]

// Clear (set to defaults)
Array.Clear(dst, 0, dst.Length);
// dst = [0, 0, 0, 0, 0]
// Add: using System.Linq;
int[] nums = { 1, 2, 3, 4, 5 };

int   sum    = nums.Sum();        // 15
double avg  = nums.Average();    // 3.0
int   max    = nums.Max();        // 5
int   min    = nums.Min();        // 1
int   count  = nums.Count();      // 5

// Filter with Where
int[] evens = nums.Where(x => x % 2 == 0)
                  .ToArray();    // [2, 4]

// Transform with Select
int[] doubled = nums.Select(x => x * 2)
                    .ToArray(); // [2,4,6,8,10]

🔲 Multi-Dimensional Arrays
Level 6 of 8

C# supports true multi-dimensional (rectangular) arrays. Think of a 2D array as a grid/table.

// 3 rows × 4 columns
int[,] grid = new int[3, 4];

// Initialize inline
int[,] matrix = {
    { 1, 2, 3 },
    { 4, 5, 6 },
    { 7, 8, 9 }
};

// Access: [row, column]
Console.WriteLine(matrix[1, 2]); // 6
Console.WriteLine(matrix[2, 0]); // 7

// Dimensions
Console.WriteLine(matrix.GetLength(0)); // 3 (rows)
Console.WriteLine(matrix.GetLength(1)); // 3 (cols)

Interactive — 3×3 Matrix

Looping a 2D Array

for (int row = 0; row < matrix.GetLength(0); row++)
{
    for (int col = 0; col < matrix.GetLength(1); col++)
    {
        Console.Write($"{matrix[row, col],4}");
    }
    Console.WriteLine();
}

3D and Beyond

// 3-dimensional array
int[,,] cube = new int[3, 3, 3];
cube[0, 1, 2] = 42;

🪜 Jagged Arrays
Level 7 of 8

A jagged array is an array of arrays — each inner array can have a different length. Hence "jagged".

// Declare array of 3 arrays
int[][] jagged = new int[3][];

// Each row has its own size
jagged[0] = new int[] { 1, 2 };
jagged[1] = new int[] { 3, 4, 5, 6 };
jagged[2] = new int[] { 7 };

// Access: [row][col]
Console.WriteLine(jagged[1][2]); // 5

Visual — Jagged Array

Looping a Jagged Array

for (int i = 0; i < jagged.Length; i++)
{
    for (int j = 0; j < jagged[i].Length; j++)
    {
        Console.Write(jagged[i][j] + " ");
    }
    Console.WriteLine();
}

Jagged vs Multi-Dimensional

💡
Multi-dim [,]: rectangular grid, all rows same length
Jagged [][]: flexible, each row any length, slightly more flexible but needs more memory per row (separate heap objects). 
// Inline initialization
int[][] jag = {
    new int[] { 1, 2, 3 },
    new int[] { 4 },
    new int[] { 5, 6 }
};
