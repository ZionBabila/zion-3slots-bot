# מקליד C# ל-Unity

אפליקציית הקלדה עיוורת בסטייל TypingClub, שמלמדת הקלדה דרך קוד C# אמיתי בדגש על MonoBehaviour ופונקציות Unity נפוצות.

## הפעלה מקומית

פתחו את `index.html` ישירות בדפדפן — אין צורך בשרת או בהתקנה.

## אונליין

מתפרסם אוטומטית ל-GitHub Pages בכל פעם שמשתנה תוכן התיקייה הזו (דרך `.github/workflows/deploy-typing-tutor.yml`).
הלינק החיים מופיע בכרטיסיית **Pages** בהגדרות הריפו, ובסטטוס ה-deployment של ה-Actions run.
