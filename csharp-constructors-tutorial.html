What is new?

The new keyword does three things:

  1. Allocates memory on the heap
  2. Calls the constructor
  3. Returns a reference to the object

✍️ Constructor Syntax
Level 2 of 7 — Memory-first approach

A constructor is a special method that runs automatically when you create an object with new.

Anatomy — remember every piece

🧠 Syntax Pattern
public  ClassName  (type param1, type param2)
  ↑         ↑              ↑
access    same name      parameters
modifier  as class       (optional)

{
    // set fields here
    this.Field1 = param1;
}

Key rules to memorise

  • Same name as the class
  • No return type — not even void
  • Called automatically with new
  • Can be overloaded (multiple constructors)

Full example

class Person
{
    // Fields
    public string Name;
    public int    Age;

    // Constructor  ← no return type!
    public Person(string name, int age)
    {
        this.Name = name;
        this.Age  = age;
    }
}

// Creating objects
Person p1 = new Person("Alice", 30);
Person p2 = new Person("Bob",   25);

🔧 Types of Constructors
Level 3 of 7
ℹ️
A default constructor takes no parameters. If you write no constructor at all, C# auto-generates one.
class Dog
{
    public string Name;
    public int    Age;

    // Default constructor — no parameters
    public Dog()
    {
        Name = "Unknown";
        Age  = 0;
    }
}

Dog d = new Dog(); // Name="Unknown", Age=0
⚠️
Once you define any constructor with parameters, C# removes the auto-generated default one. You must write it explicitly if you still need it.
ℹ️
Pass data at creation time. This is the most commonly used type.
class Dog
{
    public string Name;
    public int    Age;

    // Parameterized constructor
    public Dog(string name, int age)
    {
        this.Name = name;
        this.Age  = age;
    }
}

Dog rex  = new Dog("Rex",  3);
Dog luna = new Dog("Luna", 1);
ℹ️
A copy constructor takes an instance of the same class and duplicates it.
class Dog
{
    public string Name;
    public int    Age;

    // Copy constructor
    public Dog(Dog other)
    {
        this.Name = other.Name;
        this.Age  = other.Age;
    }
}

Dog original = new Dog("Rex", 3);
Dog copy      = new Dog(original);
// copy.Name = "Rex", copy.Age = 3
// They are SEPARATE objects
ℹ️
A static constructor runs once — before the first object is created. Used to initialise static (shared) data.
class AppConfig
{
    public static string Version;
    public static int    MaxUsers;

    // Static constructor — no access modifier, no params
    static AppConfig()
    {
        Version  = "1.0";
        MaxUsers = 100;
    }
}
// Runs automatically before first use
⚠️
Static constructors: no access modifier, no parameters, called once automatically.

🔗 this & Constructor Chaining
Level 4 of 7

What is this?

this refers to the current instance of the class. Its most common use: disambiguate when a parameter has the same name as a field.

class Car
{
    public string Model;   // field

    public Car(string Model)  // same name as field!
    {
        this.Model = Model;
        //  ↑ field    ↑ parameter
    }
}
💡
Without this., both sides refer to the parameter, so the field would never be set.

Constructor Chaining with : this()

Call one constructor from another to avoid repeating code.

class Server
{
    public string Host;
    public int    Port;
    public bool   Secure;

    // Full constructor
    public Server(string host, int port, bool secure)
    {
        Host   = host;
        Port   = port;
        Secure = secure;
    }

    // Chains to full constructor — default port 80
    public Server(string host) : this(host, 80, false) { }

    // Chains — secure defaults to port 443
    public Server(string host, bool secure)
        : this(host, 443, secure) { }
}

Server s1 = new Server("localhost");
Server s2 = new Server("api.app.com", true);
💡
The chained constructor runs first, then the body of the calling constructor.

Properties vs Fields

Best practice: use properties instead of public fields.

class Person
{
    // Property (recommended)
    public string Name { get; set; }
    public int    Age  { get; private set; } // read-only outside

    public Person(string name, int age)
    {
        Name = name;  // same as this.Name = name
        Age  = age;
    }
}

// Modern C# — Primary Constructor (C# 12)
class Point(int x, int y)
{
    public int X { get; } = x;
    public int Y { get; } = y;
}

🏛️ The 4 Pillars of OOP
Level 5 of 7

Encapsulation — hide the internal state, expose only what's needed.

class BankAccount
{
    private decimal _balance; // hidden!

    public BankAccount(decimal initial)
    {
        _balance = initial;
    }

    public void Deposit(decimal amount)
    {
        if (amount > 0) _balance += amount;
    }

    public decimal GetBalance() => _balance;
}
💡
Nobody can set _balance = -9999 directly. They must go through Deposit() which validates input.

Inheritance — a child class gets all the fields and methods of its parent.

class Animal
{
    public string Name;
    public Animal(string name) { Name = name; }
    public virtual void Speak() => Console.WriteLine("...");
}

class Dog : Animal  // ← inherits Animal
{
    public Dog(string name) : base(name) { } // ← calls parent ctor
    public override void Speak() => Console.WriteLine("Woof!");
}

Dog d = new Dog("Rex");
d.Speak(); // "Woof!"
⚠️
: base(...) calls the parent constructor. Always chain to the base if it requires parameters.

Polymorphism — same method call, different behaviour depending on the actual type.

Animal[] animals = {
    new Dog("Rex"),
    new Cat("Luna"),
    new Bird("Tweety")
};

foreach (var a in animals)
    a.Speak(); // each calls its OWN Speak()

// Output:
// Woof!
// Meow!
// Tweet!

Abstraction — define a contract without implementation. Use abstract or interface.

abstract class Shape
{
    public abstract double Area();  // no body
}

class Circle : Shape
{
    double _r;
    public Circle(double r) { _r = r; }
    public override double Area() => Math.PI * _r * _r;
}

class Square : Shape
{
    double _s;
    public Square(double s) { _s = s; }
    public override double Area() => _s * _s;
}

📋 Syntax Cheat Sheet
Level 6 of 7 — Save this page!

Every syntax pattern in one place. Refer back whenever you forget.

1 · Basic Class + Constructor
class ClassName
{
    public Type Field;          // field
    public Type Prop { get; set; } // property

    public ClassName(Type param)  // constructor
    {
        this.Field = param;
    }
}
2 · All Constructor Types
// Default (no params)
public MyClass() { }

// Parameterized
public MyClass(string x, int y) { ... }

// Copy
public MyClass(MyClass other) { ... }

// Static (once, no modifier, no params)
static MyClass() { ... }
3 · Constructor Chaining
// Call another ctor in same class
public MyClass(string x) : this(x, 0) { }

// Call parent class ctor
public Child(string x) : base(x) { }
4 · Inheritance + Override
class Parent
{
    public virtual void Method() { }
}

class Child : Parent
{
    public override void Method() { }
}
5 · Abstract Class & Interface
// Abstract class
abstract class Base
{
    public abstract void Do();   // must implement
    public virtual  void Log() { } // optional override
}

// Interface
interface IRunnable
{
    void Run();
}

class Task : Base, IRunnable
{
    public override void Do()  { }
    public         void Run() { }
}
6 · Access Modifiers Quick Ref
public            // accessible everywhere
private           // only within this class
protected         // this class + child classes
internal          // same assembly/project
protected internal // protected OR internal
7 · Object Creation Patterns
// Standard
Dog d = new Dog("Rex", 3);

// var (type inferred)
var d = new Dog("Rex", 3);

// Object initializer (sets properties)
var d = new Dog { Name = "Rex", Age = 3 };

// Target-typed new (C# 9+)
Dog d = new("Rex", 3);
