📦 What is an Array?
Fixed-size collection of same-type elements

An array stores many values under one variable name, in a numbered row of boxes.

42[0]
17[1]
99[2]
5[3]
73[4]

// Without array — messy
int s1=42, s2=17, s3=99;

// With array — clean
int[] scores = { 42, 17, 99 };
💡
Arrays start at index 0. A 5-element array uses indices 0–4.

✍️ Declaring & Initialising
3 ways to create an array

Declare then assign

int[] nums = new int[3];
nums[0] = 10;
nums[1] = 20;
nums[2] = 30;

Inline initializer

int[] nums = new int[] { 10, 20, 30 };

Shorthand (most common)

int[] nums = { 10, 20, 30 };
💡
This is the one you'll use most often.

Without values, elements get defaults:

int[]    → 0
double[] → 0.0
bool[]   → false
string[] → null

🎯 Accessing Elements
Read, write, Length, ranges

Use [] to read or write elements.

string[] fruits = { "🍎", "🍌", "🍒", "📅" };
Console.WriteLine(fruits[0]); // 🍎
fruits[1] = "🫐"; // change Banana to Blueberry

🔁 Loops
for / foreach / common patterns
int[] s = { 85,92,78 };
for (int i=0; i<s.Length; i++)
    Console.WriteLine(s[i]);
💡
Use for when you need the index or want to modify elements.
string[] c = { "Red","Green","Blue" };
foreach (string color in c)
    Console.WriteLine(color);
⚠️
foreach is read-only — you can't modify array elements through the loop variable.
// Sum
int sum = 0;
foreach (int n in arr) sum += n;

// Max
int max = arr[0];
for (int i=1; i<arr.Length; i++)
    if (arr[i] > max) max = arr[i];

// Reverse loop
for (int i=arr.Length-1; i>=0; i--)
    Console.Write(arr[i]+" ");

🛠️ Array Methods
Sort, Search, Copy, LINQ
int[] a = { 5,2,8,1 };
Array.Sort(a);       // [1,2,5,8]
Array.Reverse(a);    // [8,5,2,1]
Array.Fill(a, 0);    // [0,0,0,0]
int[] a = { 1,2,5,8 }; // sorted!
int i = Array.BinarySearch(a, 5); // 2
int j = Array.IndexOf(a, 99);     // -1 (not found)
⚠️
BinarySearch requires the array to be sorted first.
// using System.Linq;
int[] n = { 1,2,3,4,5 };
n.Sum()              // 15
n.Max()              // 5
n.Average()          // 3.0
n.Where(x=>x%2==0).ToArray() // [2,4]

🔲 Multi-Dimensional
2D arrays — grids and matrices
int[,] m = {
    { 1,2,3 },
    { 4,5,6 },
    { 7,8,9 }
};
m[1,2] // 6  (row 1, col 2)
m.GetLength(0) // 3 rows
m.GetLength(1) // 3 cols

🪜 Jagged Arrays
Array of arrays — each row any length
int[][] jag = new int[3][];
jag[0] = new int[] { 1,2 };
jag[1] = new int[] { 3,4,5,6 };
jag[2] = new int[] { 7 };

jag[1][2] // 5  ← [row][col]
💡
[,] = rectangular (all rows same length)
[][] = jagged (each row any length)
